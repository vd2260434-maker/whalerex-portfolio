Vercel Deployment & Security

Environment variables configuration guide

🔐 Secure Environment Variables Checklist

Configure these variables inside your Vercel Project Dashboard → Settings → Environment Variables:

Variable Purpose Default Fallback Status
ADMIN_USERNAME Admin login username Configured in Vercel Protected
ADMIN_PASSWORD Admin login password •••••••••••• Protected
JWT_SECRET Cryptographic token signing key •••••••••••• Protected

🚀 How to Deploy to Vercel in 1-Click:

  1. Open vercel.com/new in your browser.
  2. Import your repository (or drag & drop your project directory).
  3. In the project settings, add the environment variables above.
  4. Click Deploy. Vercel automatically deploys your static portfolio and serverless admin APIs without any build commands.
